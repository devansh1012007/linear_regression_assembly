## How / Why
NASM 2.16.03 was built from source (no sudo/apt in sandbox). The FMA harness
initially measured ~20 GFLOP/s because gcc spilled the accumulator array to
memory (address escapes); fixed with named-register macro chains — objdump
verified register-resident FMAs. The depadd clock probe was folded by gcc
until written as inline asm. Both fixes are exactly why "measure, then trust
the harness" (G0: peak within 10% of theory — measured 57.61 vs
16 flop/cy × 3.567 GHz = 57.07, 0.9%).
